# Shikizilla roadmap

Цель проекта — удобный mobile-first клиент Shikimori внутри Telegram. Работа со
списком и поиск аниме являются основным сценарием, а конструктор карточек —
дополнительным действием из каталога и страницы тайтла.

- [x] публичная страница тайтла;
- [x] OAuth-вход через Shikimori;
- [x] библиотека по всем шести статусам;
- [x] изменение статуса и оценки;
- [x] отметка просмотренной серии;

- [x] создание и отправка карточки из любого тайтла;
- [x] отдельные публичный и Telegram-сценарии навигации.

- [ ] обсуждения и комментарии;
- [ ] личные сообщения и счётчики непрочитанного;
- [ ] избранное и клубы.

## Правила развития

- не превышать ограничения Shikimori API: 5 запросов/с и 90 запросов/мин;
- использовать GraphQL для новых каталоговых данных, REST v2 — для user rates;
- сохранять основные сценарии доступными с клавиатуры и на экране 375 px;
- не блокировать каталог и карточки отсутствием авторизации Shikimori;
- добавлять тесты для каждого нового API-контракта.
